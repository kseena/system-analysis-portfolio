# На что обращаю внимание при проектировании

### Не только happy path

Система редко работает исключительно по идеальному сценарию. Поэтому в кейсах отдельно рассматриваю:

* ошибки валидации;
* недоступность внешних сервисов;
* таймауты;
* повторные запросы;
* некорректные действия пользователей;
* конфликтующие состояния.

### Данные

При проектировании БД учитываю:

* структуру и связи данных;
* ограничения;
* нормализацию;
* целостность данных;
* дальнейшее развитие модели.

### API и интеграции

При описании взаимодействия систем учитываю:

* структуру запросов и ответов;
* статусы и ошибки;
* авторизацию;
* повторную отправку запросов;
* идемпотентность;
* особенности синхронного и асинхронного взаимодействия.
